## Projeto

Sistema em Java para calcular o aluguel de carros, motos e carros elétricos.

O projeto usa:
- Abstração
- Herança
- Sobrescrita
- Polimorfismo
- Interface
- Encapsulamento

## Saída do programa

Exemplo de saída esperada:

=== VEÍCULOS ===
Placa: ABC-1234 | Modelo: Toyota Corolla
Aluguel: R$ 495.0

Placa: DEF-5678 | Modelo: Honda CG
Aluguel: R$ 320.0

Placa: GHI-9012 | Modelo: Tesla Model 3
Aluguel: R$ 705.0

=== TESTE MOTO 5 DIAS ===
Aluguel: R$ 340.0

=== RECARGA ===
Recarga: R$ 24.0

## Conferência dos valores

- Carro, 3 dias: R$ 495.0
- Moto, 4 dias: R$ 320.0
- Moto, 5 dias: R$ 340.0
- Carro elétrico, 3 dias: R$ 705.0
- Recarga do carro elétrico, 3 dias: R$ 24.0
